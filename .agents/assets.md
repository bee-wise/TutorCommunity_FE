# BeeWise asset catalog (Cloudinary)

Hand-curated, classified by content. New images/videos go to Cloudinary (`npm run assets:upload -- <file> <public_id>`), not `apps/*/public`; never import files across apps. Raw list: `.agents/assets-inventory.md` (generated by `npm run assets:sync`, which also lists new unclassified assets).

**URL** = `https://res.cloudinary.com/xcrm6ykz/image/upload/<transform>/<path>`
- PNG/JPG: transform `f_auto,q_auto,w_<rendered px×2>`; add `e_trim/` before it to cut transparent padding (all 1440×1440 elements have wide padding).
- SVG: no transform, use `upload/<path>` directly.
- `next/image` with width/height, Vietnamese `alt`; decorative → `alt=""`. Max one mascot illustration per viewport, never over text. Never redraw or recolor these in SVG/CSS; if nothing fits, leave a TODO slot and tell the user.
